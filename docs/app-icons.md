# App icon sources

Brand marks on `/apps` are stored locally so the page does not depend on a
third-party icon request at render time.

* `aws.ico` - AWS favicon from <https://aws.amazon.com/favicon.ico>.
* `forgejo.svg` - Forgejo mark from <https://simpleicons.org/>.
* `glama.ico` - Glama favicon from <https://glama.ai/favicon.ico>.
* `lunch-money.ico` - Lunch Money emblem from
  <https://lunchmoney.app/favicon.ico>. Usage follows the
  [Lunch Money media kit](https://lunchmoney.app/media-kit/).
* `playwright.svg` - Playwright mark from
  <https://playwright.dev/img/playwright-logo.svg>.
* `reddit.svg` - Reddit mark from <https://simpleicons.org/>.
* `skillsmp.ico` - SkillsMP favicon from <https://skillsmp.com/favicon.ico>.
* `steam.svg` - Steam mark from <https://simpleicons.org/>.
* `trello.svg` - Trello mark from <https://simpleicons.org/>.

The marks identify their respective services and do not imply endorsement.
